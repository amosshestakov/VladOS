# VladOS

Оболочка для Android TV с управлением пультом, единым центром настроек и обновлением через GitHub Releases. Пакет приложения: `ru.ilya.alitahome`. Минимальная версия: Android 6 / API 23.

## Установка и обновление телевизора

Скачайте APK из раздела [Releases](https://github.com/amosshestakov/VladOS/releases). Первый выпуск с функцией обновления установите поверх имеющегося VladOS. Данные приложения при обычном обновлении сохраняются.

Далее на телевизоре: **Настройки → Система → Обновление VladOS → Скачать и установить**. Android запросит подтверждение установки. Если потребуется, разрешите установку приложений из VladOS.

Телевизор скачивает последнюю стабильную версию и проверяет SHA-256, размер APK, пакет, номер версии и совпадение подписи с установленным приложением. Нужен доступ к GitHub и его серверам загрузки. Публичный выпуск не требует входа в GitHub на телевизоре.

## Главный экран

На проверенном Xiaomi Android 9 обычное назначение приложения главным экраном не удерживается прошивкой. Возврат по Home реализован через включаемую службу специальных возможностей VladOS. Она обрабатывает появление главного экрана Xiaomi и не читает содержимое экрана.

**Настройки → Система → Открыть стандартную оболочку Xiaomi** открывает штатный главный экран и приостанавливает автовозврат до следующего открытия VladOS в текущем процессе. Настройки панели и системные подтверждения остаются у Android/Xiaomi.

## Сборка

Нужны JDK 17, PowerShell 7 и Android SDK с пакетами `platforms;android-28` и `build-tools;35.0.0`. Укажите пути через `JAVA_HOME` и `ANDROID_HOME`.

```powershell
./Build.ps1 -Unsigned
```

Для APK, который обновит существующий VladOS, нужен **тот же ключ подписи**, которым подписана установленная версия. Он хранится отдельно от репозитория. Перед подписанной сборкой задайте локальные переменные `VLADOS_KEYSTORE`, `VLADOS_STORE_PASSWORD`, `VLADOS_KEY_ALIAS`, `VLADOS_KEY_PASSWORD`, затем запустите:

```powershell
./Build.ps1
```

Результат: `dist/VladOS.apk`. Новый случайный ключ не подходит для обновления имеющейся установки. Не удаляйте приложение ради смены ключа: это удалит его локальные данные.

## Выпуск новой версии из дома

1. Измените `android:versionCode` и `android:versionName` в `app/src/main/AndroidManifest.xml`. Номер `versionCode` должен увеличиваться.
2. Соберите и проверьте подписанный APK.
3. Сохраните изменения в Git и отправьте в `main`.
4. Создайте и отправьте тег, соответствующий версии, например `v0.5.5`.
5. Напишите изменения в отдельный текстовый файл и выполните:

```powershell
./Publish-Release.ps1 -Apk ./dist/VladOS.apk -NotesFile ./release-notes.md
```

Нужен установленный официальный GitHub CLI (`gh`) с входом в аккаунт владельца репозитория. Скрипт проверит пакет и сертификат, создаст черновик релиза, загрузит APK и `update.json`, затем опубликует готовый выпуск. Телевизор увидит его при следующей проверке обновлений. Подключение компьютера к телевизору не требуется.

GitHub Actions проверяет сборку без подписи при изменениях исходников. Этот проверочный APK не является обновлением для телевизора; ключ подписи в Actions не передаётся.

## Состав репозитория

- `app/` — Android-приложение и встроенные ресурсы.
- `tests/` — проверки отдельных механизмов.
- `upstream/` — сведения об использованных сторонних компонентах.
- `THIRD_PARTY.md` — источники и лицензии компонентов.

Репозиторий не содержит ключей подписи, Android SDK/JDK, аккаунтов HDRezka, VPN-конфигураций, журналов телевизора и личных настроек. Они не нужны для публикации исходников.
