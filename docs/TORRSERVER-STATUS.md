# Локальный TorrServe в VladOS 0.5.5

Подготовлена интеграция с сервером на самом Android TV, без постоянной работы компьютера. Модуль строгой фильтрации доступности HDRezka/Rutube не включён.

## Реализовано

- В Lampa включены раздел торрентов и настройка локального TorrServer по адресу http://127.0.0.1:8090.
- Сетевой мост поддерживает нужные локальные запросы и JSON POST. Адрес и перенаправления проверяются.
- Плеер принимает локальные адреса /stream/; запрос предварительной загрузки преобразуется в запрос воспроизведения.
- Исключение Android для HTTP ограничено 127.0.0.1. Удалённые источники продолжают использовать HTTPS.
- Существующая конфигурация HDRezka сохраняется.

## Статус проверки

На тестовом телевизоре установлен официальный клиент TorrServe MatriX 144. Штатная загрузка серверной части MatriX 150 не завершилась: сервер остался в состоянии «Не установлен». Интерфейс Lampa открывается, но локальный сервер не отвечает.

Установка серверной части, просмотр торрента, звук, перемотка, возобновление и автозапуск сервера пока не подтверждены. Выпуск 0.5.5 содержит поддержку локального сервера, а не готовую настройку просмотра торрентов.

Перед заявлением о готовности нужно успешно запустить сервер, проверить его API и воспроизвести разрешённый тестовый торрент на телевизоре. Поддержка контейнеров и кодеков зависит от Android и аппаратного декодера.
