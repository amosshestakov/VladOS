# VladOS 0.5.5

Первый публичный выпуск с обновлением через GitHub Releases. Package `ru.ilya.alitahome`, versionCode `13`.

- В настройках системы появился пункт «Обновление VladOS»: проверка новой версии, загрузка и переход к системному подтверждению установки.
- Перед установкой проверяются размер и SHA-256 файла, пакет, номер версии и совпадение сертификата с установленным приложением.
- Сохранён единый центр настроек, возврат по Home и отдельная кнопка открытия стандартной оболочки Xiaomi.
- Исправлен пустой раздел HDRezka: поиск запускается при открытии, список просмотра и выбор озвучек работают с встроенной версией Lampa.
- Для поиска используется оригинальное название; для недоступного полного видео и Premium-озвучки показывается понятное сообщение.
- Добавлена возможность открыть страницу HDRezka в отдельном встроенном окне без доступа удалённой страницы к функциям VladOS.
- Подготовлена работа с локальным TorrServe на телевизоре через `127.0.0.1:8090`.

**Ограничения:** наличие карточки в каталоге не гарантирует доступность фильма. HDRezka может требовать Premium для выбранной озвучки. Сервер TorrServe 150 на тестовом телевизоре не установлен: штатная загрузка не завершилась; воспроизведение торрентов и автозапуск сервера не подтверждены. Подробности — `docs/TORRSERVER-STATUS.md`.

На телевизоре с более ранней версией без обновлений этот APK нужно установить один раз обычным способом. Последующие версии можно устанавливать из VladOS. Настройки и аккаунты сохраняются при обновлении поверх существующего приложения с той же подписью.
