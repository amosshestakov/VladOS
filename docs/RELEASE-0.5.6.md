# VladOS 0.5.6

Обновление канала загрузки для телевизоров, на которых API и страницы релизов GitHub отвечают ошибками или таймаутами.

- Встроенное обновление сначала проверяет фиксированный канал на raw.githubusercontent.com. GitHub Releases остаётся дополнительным источником.
- После публикации стабильного релиза GitHub Actions проверяет размер и SHA-256 APK и автоматически обновляет ветку `updates` с последним установщиком и данными версии.
- Телевизор скачивает APK самостоятельно, без компьютера в домашней сети. Проверки размера, SHA-256, пакета, номера версии и совпадения сертификата сохранены.
- Исходники находятся в `main`, история версий и APK — в Releases. Ветка `updates` служит только для загрузки последнего выпуска и пересоздаётся автоматически.

Сохраняются изменения 0.5.5: единый центр настроек, выход в Xiaomi, исправления пустого раздела HDRezka и поддержка подключения к локальному TorrServe. Сервер TorrServe на тестовом телевизоре пока не установлен; просмотр торрентов не подтверждён. Вход в HDRezka не заменяет Premium-доступ к отдельным озвучкам.

Версию без нового канала на проблемной сети нужно обновить один раз вручную. После установки 0.5.6 следующие выпуски доступны через «Настройки → Система → Обновление VladOS».
